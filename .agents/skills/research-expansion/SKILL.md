# Research Expansion (GAPI / MEAR)

Use when an investigation is stalled by negative results, repeated local tuning, an uncertain/confounded effect, weak novelty, missing deployment bridge or a misleading proxy. Also use for a requested new research direction or substantial research recap.

1. **ANCHOR_GOAL:** read the owning project's goal/acceptance contract. Distinguish north-star scientific question, terminal evidence, frozen engineering gates, local proxy, and current candidate. If the goal contract is absent, elicit or reconstruct it from supplied primary material; mark inferred goals, do not silently invent.
2. **PRESERVE_NEGATIVES:** identify the rejected instance's object, precision, action set, budget, comparator, data, evidence and exact failure claim. Do not overwrite or reopen it by relabeling a hyperparameter change.
3. **DISCRIMINATE:** give the strongest currently valid result. Where empirical uncertainty truly remains, rank at most three non-isomorphic causes and their divergent predictions; choose a cheapest decisive proof/static/old-data/native probe with conditional A/B decisions.
4. **EXPAND_STRUCTURALLY:** explore only one or two justified changes among representation, accessible information timing, action granularity, downstream loss, model regime, or hardware primitive. Derive a structural delta from the actual computation, and pit it against a strong simple baseline and nearest failed route. Do not automatically prescribe familiar methods.
5. **BRIDGE_TO_TERMINAL:** check that any proxy or local improvement has an explicit causal bridge to the terminal objective, free deployment trajectory, resource ledger and independent comparator. Mark PROXY_ONLY where appropriate.
6. **ROUTE:** MAP_FLOW / DERIVE / STATIC_CHECK / EXPERIMENT / DESIGN / REPAIR / PIVOT / ACCEPT_CONDITIONAL / DEFER. If a proof settles the scoped question, conclude instead of running experiments. If blocked, state the exact dependency, then continue only genuinely feasible analysis.
7. **RECORD:** preserve evidence levels, exact rejected scopes, decision impact and candidate novelty status. Never promote hypotheses or proposed tests to observed results.

Read core/GOAL_ALIGNMENT.md, core/EXPANSION_PROTOCOL.md and (on demand) core/PROMPT_PLAYBOOK.md. For actual source/mathematics/novelty continue using the mechanism-research skill and core/OBJECT_RECONSTRUCTION.md, core/DEDUCTION_FIRST.md, core/NOVELTY_GATE.md.

Output succinctly: goal -> verified mechanism -> exact obstruction -> decisive alternatives -> cheapest discriminator / conditional decisions -> terminal bridge. Ask for missing permission only if action requires it. Never run unapproved training or mutate an external repository without authorization.
