# Scientific-writing and manuscript-review behavior cases

Use the same model, tool access, manuscript excerpts and budget for the pre-change protocol and candidate branch. Blind-review both outputs for scientific validity, argument coherence, style and actual correction value. These are `test prompts`, not passing model results.

| Case | Input setup | Expected |
| --- | --- | --- |
| SW01 | Formula-rich paper uses a new (x_t\), (W\), (y\) without definitions | A nearby `where` explains all first-use symbols, index ranges and shapes |
| SW02 | Abstract and body introduce FFN/DiT with no expansions | Expand abbreviations on first use; independently check abstract and main text |
| SW03 | Abstract invents a conjunction of edge/real-time/noisy application constraints | Identify actual system and evidence-backed setting, or use honest theoretical framing |
| SW04 | Generic gap and a simple combination of two existing methods | Identify nearest work, precise gap, effect of combination, matched component baselines |
| SW05 | Results sorted by experiment runtime and disconnected from claims | Recover a purposeful sequential or parallel experimental argument |
| SW06 | Results restate every value and omit weak outcomes | Explain mechanism, effect size, uncertainty, limitations and instructive failures |
| SW07 | Mixed axis boxes, grid strengths, font sizes and color-only line differences | Review actual exported images; require consistent, color-blind-friendly visual semantics |
| SW08 | Mixed GB/GiB, numeric units without spaces | Unify comparable units and include appropriate number–unit spaces |
| SW09 | Multiple relations under one number with ambiguous sequential vs simultaneous meaning | Use an appropriate left brace or aligned sequence without changing mathematical semantics |
| SW10 | Inconsistent variables/subscripts across diagram, equation and pseudo-code | Reconcile scientific objects, shapes and indices throughout |
| SW11 | Inconsistent bibliography names/initials, journal formatting, pages/issues | Use venue style and verified publication metadata |
| SW12 | Important gap claim cites unrelated weak studies | Examine direct primary evidence and nearest strong competing work |
| SW13 | Caption mentions (a)(b) with unlabeled panels; headings mix case styles | Match visible panels and captions; enforce venue-level consistency |
| SW14 | Long series of defensive negations and artificial hyphens | Rewrite as constructive subject–verb relationships while retaining real negative findings |
| SW15 | Abrupt unexplained tense changes in a single results paragraph | Align tense to completed procedure versus general fact/interpretation |
| SW16 | Exact impossibility theorem for one algorithm family | Preserve rigorous negative conclusion, scope it and seek a genuinely separate open direction if useful |
| SW17 | User asks simply for a new introduction paragraph | Deliver polished text without initiating research-handoff or QA ceremony |
| SW18 | Only textual PDF extraction available; asked to certify plot font and grid | Mark visual QA as unverified and request/inspect actual rendered output when available |

**Rubric:** judge scientific truth, relevance of proposed edits, clarity, constructive expression, accurate uncertainty and routing efficiency. A static syntax pass or increased positive wording is not evidence of better writing. Any fabricated results, invented references or suppressed contrary evidence is a critical regression.
